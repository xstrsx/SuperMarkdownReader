# 用户手动验证清单

Actions 构建、正式签名、静态校验与上传成功后，由**用户**下载、安装并验证。
执行 Agent 不下载 APK、不安装、不运行模拟器/真机/浏览器验收，也不等待验证结果作为交付前提。
下面所有项目在收到用户结果之前都标记为“待用户验证”。

下载入口：Actions run 的 artifact **`LiteDoc-release-bundle`**（含 APK、`SHA256SUMS`、
包体报告与 `build-info.json`）。请核对下载文件的 SHA-256 与 `SHA256SUMS` 一致。

## 先做的五项

1. 手动安装 APK；若已有正式版本，检查覆盖升级是否成功。
2. **首次启动前断网**，用 `fixtures/markdown`、`fixtures/math`、`fixtures/mermaid`、
   `fixtures/svg`、`fixtures/smiles`、`fixtures/csv` 依次打开，确认公式、图表、结构图与
   字体没有缺失（不先联网初始化）。
3. 通过系统“打开方式”“分享”“多文件分享”进入；检查中文路径、附件目录授权、返回与切换文件。
4. 恢复网络后检查远程图片；关闭“网络图片”开关后确认不再新增下载；网页 URL 不应被当网页加载。
5. 检查字号/主题/目录/搜索、PDF 打印与单图导出，尤其是**未滚动到底**时直接导出，
   以及宽表格、长代码行与宽图形。
