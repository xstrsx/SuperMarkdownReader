# ADR 0003：数学整篇一次排版（不做视口懒排版）

状态：已采纳（2026-10-02）

## 背景

方案要求“公式宏、编号和引用按整篇语义处理，不能因视口懒加载而打乱”，
并提到独立无依赖公式可启用经验证的懒排版。

## 决策

**整篇一次 `MathJax.typesetPromise(allMathElements)`**，按源顺序调用一次：

- 编号（`tags: 'ams'`）、`\label`/`\ref`/`\eqref`、`\tag` 在整篇范围内才有意义；
  多次调用会按“多个文档”处理，编号会重置、前后引用会失效；
- 表达式内的 `\newcommand`/`\def` 只在同一元素内生效，因此不依赖跨元素懒排版；
  `\gdef` 的文档级宏也只有整篇一次调用才可靠；
- 分块排版在 MathJax 中无法保留同一文档的计数器与引用表。

## 代价与缓解

- 代价：公式极多时数学排版集中在一次调用中。
- 缓解：MathJax 仅在文档确实包含公式时才加载；正文先按顶层块分批插入（用户可先读正文），
  之后再触发一次整篇排版；导出前还会等待该排版完成。
- 若日后要为“独立无依赖公式”启用懒排版，必须先证明编号/引用/宏语义不变，
  并成为独立 ADR，不默认开启。

## 已知限制

- 未打包 KaTeX 网页字体用于 Mermaid 图内数学（图内数学由 Mermaid 自带模块渲染），
  两套数学引擎互相独立。
- 文档不暴露 MathJax 配置；front matter 只作为元数据显示，不作为配置来源。
